# kode v0.2.2-alpha.4

This preview brings signed app updates, multi-device sync, and a refined mobile experience.

## Highlights

- Check for updates in Settings, with an optional beta channel and signed update packages for Apple Silicon and Intel Macs.
- Switch between paired devices on mobile, with improved session isolation and sync reliability.
- Enjoy an iOS-style glass interface and clearer mobile send-button states.
- Preview PDF and HTML files, reference workspace files in the composer, and crop screenshots before sending.
- Use the refined Model Monitor: notch-aware display behavior and more precise hover interactions.

## Fixes and improvements

- Improved Codex session status tracking for turn start, completion, and cancellation.
- Kept session-status events out of conversation history and improved asynchronous input handling.
- Improved terminal color handling and shared-memory integration.
- Updated SpecOps asset-size checks for the embedded icon bundle.
- Added detailed macOS packaging diagnostics and one retry for DMG-script failures.

## Install and update

- Download the `aarch64.dmg` for Apple Silicon or the `x86_64.dmg` for Intel, then drag kode to Applications.
- Enable beta updates in Settings to receive compatible preview releases. Older builds with a different updater public key require one manual installation.
- Update packages have a separate cryptographic signature. These preview builds use ad-hoc macOS signing and are not Apple-notarized.
